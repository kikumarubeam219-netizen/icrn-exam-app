# 集中治療認証看護師 過去問演習アプリ

2022年〜2025年度（計280問）の過去問題、解答、詳細解説、および心電図・波形・CT等の問題図を収録したWeb学習アプリです。  
PC・タブレット・スマートフォンのブラウザで快適に学習できます。

---

## 主な機能

1. **① 年度別演習モード**
   - 2025年度（70問）、2024年度（70問）、2023年度（70問）、2022年度（70問・採点対象外除外対応）から選択して学習。
   - 1問解くごとに即座に正誤判定とスプレッドシート由来の詳細な解説が表示されます。
   - 単一選択および「2つ選べ」などの複数選択に自動対応。

2. **② ランダム出題モード**
   - 出題対象（全年度または特定年度）と、出題問題数（10問 / 20問 / 35問 / 70問）を選んでシャッフル演習。

3. **③ 復習・見返し機能**
   - **間違えた問題**: 過去に誤答した問題だけを抽出して集中的に解き直せます。
   - **チェックした問題**: 問題画面で星マーク（チェック）を付けた苦手問題をいつでも見返せます。

4. **学習履歴・進捗の自動保存**
   - 解答履歴、正答率、チェックした問題はブラウザ（LocalStorage）に自動保存されます。ブラウザを閉じても前回の続きから利用可能です。

5. **図表・波形の拡大表示**
   - 問題図（心電図、人工呼吸器グラフィック、CT画像など）をクリック・タップすると全画面で鮮明に拡大表示されます。

## GitHub Pages でのデプロイ（公開）手順

本アプリは **完全な静的Webアプリケーション** として設計されているため、GitHub Pages を使って**完全無料**で数分でWeb上に公開できます。

### 手順 1: GitHubで新しいリポジトリを作成
1. [GitHub](https://github.com/) にログインし、右上の「＋」から **[New repository]** をクリックします。
2. リポジトリ名を入力します（例: `icrn-exam-app`）。
3. **Public** または **Private** を選択します。
   - ※無料アカウントの場合、GitHub Pages を利用するには原則 **Public**（公開）にする必要があります。検索エンジンにはインデックスされないよう `<meta name="robots" content="noindex, nofollow">` を設定済みです。
4. [Create repository] をクリックします。

### 手順 2: ファイルをGitHubへアップロード
Gitコマンドを使う場合（推奨）：
```bash
cd C:\Users\l0905\.gemini\antigravity\scratch\icrn-exam-app
git init
git add .
git commit -m "Initial commit: ICRN exam app"
git branch -M main
git remote add origin https://github.com/<あなたのユーザー名>/icrn-exam-app.git
git push -u origin main
```

※ Gitコマンドを使わない場合、GitHubのリポジトリ画面から「uploading an existing file」を選択して本フォルダ内のファイルをドラッグ＆ドロップしてコミットすることも可能です。

### 手順 3: GitHub Pages を有効化する
1. GitHubのリポジトリ画面上部にある **[Settings]**（設定）タブをクリックします。
2. 左メニューの **[Pages]** をクリックします。
3. **Branch** の設定で、`None` を **`main`** に変更し、フォルダは **`/(root)`** のまま **[Save]** をクリックします。
4. 1〜2分待つと、画面上部に公開URL（例: `https://<あなたのユーザー名>.github.io/icrn-exam-app/`）が表示されます。

### 手順 4: スマートフォンでアプリ化（PWA対応）
発行されたURLをスマートフォンのブラウザで開きます：
- **iPhone (Safari)**: 画面下の共有アイコン（四角から矢印）をタップし、「**ホーム画面に追加**」を選択。
- **Android (Chrome)**: 右上のメニュー（︙）から「**ホーム画面に追加**」または「**アプリをインストール**」を選択。

これで、スマートフォンのホーム画面に専用アプリアイコンが追加され、いつでもワンタップでアプリとして起動できます。

## PC・ローカル環境での利用方法

インターネットに公開せず、ご自身のPCや自宅Wi-Fiだけで使うことも可能です。

1. 本フォルダ内の **`起動.bat`** をダブルクリックします。
2. 自動的にブラウザが立ち上がり、アプリが使用可能になります。
3. 画面に表示されるローカルIPアドレス（例: `http://192.168.x.x:8080`）をお持ちのスマートフォンに入力すれば、同じWi-Fi内であればスマホからもアクセスできます。
